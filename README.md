# 🍽️ FoodHub

**FoodHub** is a full-stack food ordering web application built using the **MERN stack** (MongoDB, Express, React, Node.js). It allows users to browse delicious meals, add items to their cart, and place orders seamlessly — delivering a smooth and delightful online food ordering experience.

---

## 🚀 Features

- 🛍️ **Add to Cart**: Browse meals and instantly add them to your cart.
- 🛒 **View Cart**: Review items in your cart with detailed information and pricing.
- 📦 **Place Orders**: Seamlessly checkout and place orders with one click.
- 🔐 **User Authentication**: Secure login/signup functionality.
- 📱 **Responsive Design**: Optimized for mobile and desktop views.

---

## 🛠️ Tech Stack

| Tech           | Description                         |
|----------------|-------------------------------------|
| MongoDB        | NoSQL Database for storing orders, users, and products |
| Express.js     | Backend web framework for API handling |
| React.js       | Frontend library for building UI components |
| Node.js        | JavaScript runtime environment for backend |
